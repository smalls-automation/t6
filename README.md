# t6 Todo App

A simple, no‑persistence todo web application built with vanilla HTML, CSS, and JavaScript. The app runs entirely in the browser—no server or database required.

## Features
- Add new todo items
- Mark items as completed/uncompleted
- Delete items
- All data is stored in memory for the session (no persistence across reloads)

## Getting Started
1. Clone the repository:
   ```
   git clone https://github.com/smalls-automation/t6.git
   ```
2. Open `index.html` in any modern web browser.

That's it! No build steps or dependencies needed.
