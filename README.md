# t6 Todo App

A simple, no‑persistence todo web application built with vanilla HTML, CSS, and JavaScript. All data is stored in the browser's `localStorage` so the app works offline and requires no backend.

## Features
- Add new todo items
- Mark items as completed / uncompleted
- Delete todo items
- Persistent across page reloads via `localStorage`

## Running the app
Open `index.html` in any modern browser. No build step or server is required.
